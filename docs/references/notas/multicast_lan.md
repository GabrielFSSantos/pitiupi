# Multicast em LAN (nota)

IP multicast envia um datagrama que roteadores/switches encaminham aos assinantes do grupo (ex.: `224.0.0.3`).

Na sala de aula:

- Todos os peers devem estar na mesma sub-rede e permitir IGMP/multicast.
- Wi‑Fi com “client isolation” impede descoberta.

Operação no código: [appendix_portas_e_multicast.md](../../documentation/appendix_portas_e_multicast.md).

RFC introdutória: ver entrada `rfc1112` em [bibliografia.bib](../bibliografia.bib).
