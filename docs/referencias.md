# Referências

Os capítulos [rede.md](rede.md) e [plugins.md](plugins.md) já descrevem o que o Pitiupi faz. Os livros e as RFCs abaixo são o pano de fundo, não um segundo manual do código.

- Kurose e Ross — *Redes de Computadores e a Internet*.
- Tanenbaum — *Redes de Computadores*.
- Peterson e Davie — *Redes de Computadores*.
- RFC 768 (UDP), RFC 793 (TCP), RFC 1112 e RFC 3376 (multicast).

Entradas BibTeX: [references/bibliografia.bib](references/bibliografia.bib).

Documentação Java usada pelo núcleo: [serialização](https://docs.oracle.com/en/java/javase/17/docs/specs/serialization/index.html), [ServiceLoader](https://docs.oracle.com/en/java/javase/17/docs/api/java.base/java/util/ServiceLoader.html), `MulticastSocket` e Swing.
